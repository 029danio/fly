## 机场选购指南

**选机场节点前必看：省掉许多麻烦，出海冲浪更顺畅**

1. **为何推荐中转机场**：
   - **价格优势**：中转机场通常价格较低。
   - **更大带宽**：中转机场一般能提供更大的带宽，确保连接速度更快。
   - **连接稳定**：专线的优势在于不过墙，延迟低，网络波动小，提供更加顺畅的日常使用体验。
   - **公网绕路问题**：使用公网时，出口有时会绕路，导致网络波动，从而影响使用体验。

2. **选择机场的关键因素**：
   - **资金实力**：选择机场节点时需要考虑其资金支持。
   - **总带宽大小**：速度取决于机场的总带宽。
   - **资源质量**：稳定性依赖于机场的资源质量，尤其是上游线路的质量。
   - **解锁能力**：解锁能力取决于机场主的落地和解锁服务商的质量。

3. **防火墙和政策变化**：
   - **政策变化**：防火墙的政策每年都在变化，特别是在重大节日或会议期间，干扰可能会加剧。
   - **备用机场**：建议购买2到4个备用机场，以应对单个机场被封锁的情况。
   - **不限时套餐**：推荐选择不限时套餐，一次购买即可一直使用，直到流量用完。

4. **避免免费服务**：
   - **免费服务的风险**：避免使用免费分享的VPN或SS/SSR节点，这些服务流量少，容易被GFW封锁，很快就无法使用。
   - **付费机场的优势**：付费机场提供更稳定和流畅的使用体验。

## 常见问题 FAQ

### 机场和 VPN 有什么区别？
广义上都是翻墙工具。"机场"是中文圈对订阅制代理服务的俗称，基于 Shadowsocks / V2Ray / Trojan 等协议，通过订阅链接在客户端（如 Clash、Shadowrocket）中使用；传统 VPN 则是整机隧道。本页推荐的机场节点均为国内实测可用，速度与稳定性普遍优于普通 VPN。

### 机场会被墙吗？买了之后用不了怎么办？
有可能。GFW 会不定期封锁 IP 和端口，这是所有机场的共性风险。应对办法：① 选择有多个入口 / 经常更新线路的机场；② 手头备 2～4 个机场；③ 优先不限时套餐，封了也不心疼。本页榜单每月更新，失联的机场会及时下架。

### iOS（苹果手机）用什么客户端连接机场？
 iOS 端主流是 Shadowrocket（小火箭）和 Stash，需要外区 Apple ID 下载。安卓用 ClashMeta / v2rayNG，Windows / Mac 用 Clash Verge 或 v2rayN。订阅链接复制进客户端即可一键导入节点。

### 机场节点能解锁 ChatGPT 和 Netflix 吗？
本页推荐的三家机场均支持解锁 ChatGPT、Netflix、Disney+、TikTok 等流媒体与 AI 应用，具体以各机场详情页的"解锁能力"说明为准，购买前可用月付 / 短期套餐先实测。

### 一个月大概需要多少流量？
轻度使用（聊天、查资料）50～100G 足够；经常刷视频、追剧建议 200G 以上；下载、AI 高频用户直接上 500G+ 或不限时套餐。拿不准先买月付试一个月，再按实际用量升级。
